# Documentación del Proyecto

Todos los archivos de documentación técnica, diseño y manuales del sistema se encuentran organizados dentro de la carpeta [`/docs`](./docs).

## Contenido de `/docs`

* **[DiagramaUML.mmd](./docs/DiagramaUML.mmd)**: Diagrama de clases en formato Mermaid que detalla la arquitectura y estructura del sistema.
* **[DocumentacionEstructuras.docx](./docs/DocumentacionEstructuras.docx)**: Documento explicativo de las estructuras de datos dinámicas utilizadas en el servidor.
* **[ManualDeUsuarios.docx](./docs/ManualDeUsuarios.docx)**: Guía de uso paso a paso para la configuración e interacción con el juego.
* **[protocolo.md](./docs/protocolo.md)**: Especificación detallada de los protocolos de comunicación Cliente–Servidor (WebSockets/TCP) y Serial (Arduino).
* **[RegistroDePartida.txt](./docs/RegistroDePartida.txt)**: Registro de Partida
